# YT Like

Мини-приложение для Android, которое лайкает трек, играющий в YouTube Music, в одно касание: из шторки, с экрана блокировки или из плитки быстрых настроек. Нужно для HyperOS и других прошивок, где системный медиаплеер не показывает кнопку лайка.

## Как это работает

API и авторизация не нужны. Приложение получает доступ к уведомлениям и через него видит медиасессию YouTube Music. Лайк ставится тем же способом, что и в стандартном плеере Android:

1. `PlaybackState.CustomAction` сессии (кнопка «Нравится» стандартного плеера);
2. если такого действия нет — кнопка в уведомлении самого YouTube Music;
3. если и её нет — `setRating(thumb up)`.

## Где появляется кнопка

- **Уведомление** с треком и красной кнопкой «👍». Беззвучное, видно в шторке и на экране блокировки. Показывается только пока играет или стоит на паузе YouTube Music.
- **Плитка «Лайк трека»** в шторке быстрых настроек. Работает без разблокировки.

- **Долгое нажатие «громкость −»** (полсекунды) — лайк, не глядя на телефон. Громкость при этом не меняется, короткое нажатие убавляет её как обычно. В приложении можно переключить на дизлайк или выключить. Работает только при включённом экране (заблокированном тоже). При выключенном экране Android не передаёт кнопки громкости спецвозможностям. Во время звонка кнопки не перехватываются.

Вибрация после нажатия: одна короткая — готово, две короткие — лайк снят, одна длинная — ошибка.

> Повторное нажатие обычно снимает лайк — так ведёт себя сам YouTube Music.

## Установка

1. Скачай `ytlike.apk` из релиза [latest](../../releases/tag/latest) и установи.
2. Открой **YT Like**, нажми «Выдать доступ к уведомлениям» и включи YT Like.
3. Разреши уведомления и нажми «Добавить плитку».
4. На Xiaomi/HyperOS:
   - включи «Автозапуск»;
   - в «Контроле активности» выбери «Нет ограничений»;
   - разреши уведомления на экране блокировки.

   HyperOS по умолчанию скрывает содержимое уведомлений на заблокированном экране, и приложение не может это изменить. Нажми в YT Like «Показ на экране блокировки» (откроются настройки канала «Кнопка лайка») и в пункте «На экране блокировки» выбери показ содержимого. Иначе вместо кнопки будет видно только «YT Like».
5. Для кнопки громкости нажми «Включить в спецвозможностях» и включи «YT Like: лайк кнопкой громкости». Если переключатель неактивен (Android блокирует это для приложений не из магазина): Настройки приложения → ⋮ → «Разрешить ограниченные настройки».
6. Включи трек в YouTube Music и нажми «👍 Лайкнуть сейчас» в приложении.

### Если лайк не срабатывает

Внизу экрана приложения есть список действий плеера и кнопок его уведомления. Найди нужное (`Like`, `Нравится`, `thumbs up`…) и нажми «Использовать как лайк». Выбор сохраняется. В разделе «Диагностика» показан полный дамп сессии. Тот же дамп пишется в logcat с тегом `YtLike`.

## Часы и наушники

- **Wear OS и часы, которые поддерживают кнопки уведомлений**: кнопка «👍» придёт вместе с уведомлением.
- **Huawei Watch GT и наушники**: кнопки уведомления не работают. Часы рисуют собственный плеер, а наушники отправляют только стандартные медиакнопки, которые Android передаёт прямо в плеер. Обходной путь — голосовой ассистент («Окей, Google, мне нравится эта песня»).

## Сборка

APK собирает GitHub Actions (`.github/workflows/build.yml`) при каждом пуше и выкладывает в релиз `latest`. Локально: `./gradlew assembleRelease`, нужен Android SDK.

Подпись — debug-ключ из репозитория (`app/debug.keystore`). Поэтому каждая новая сборка ставится поверх старой без удаления.
